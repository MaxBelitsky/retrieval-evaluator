# Security Policy

## Supported versions

Security fixes are applied to the latest released version of `retrieval-evaluator`.

## Report a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/MaxBelitsky/retrieval-evaluator/security/advisories/new).

Do not include API keys, credentials, private corpus content, or other secrets in a report. You will receive an acknowledgement and coordinated-disclosure guidance after the report is reviewed.
